# Monte Carlo uncertainty experiment

Protocol fixed before execution, 2026-10-12. Research only; production and native ledgers are protected.

Evaluate 2023–2025, using strictly earlier weeks for every fit, profile, normalization reference and error pool. This is exposed historical development, not native forward evidence. Keep all candidates; do not select a winner by historical return.

Arms: no-vig moneyline; exact restored v1.16; joint empirical market residual simulation; price-calibrated empirical simulation; model-adjusted empirical simulation; whole-team-game multiplier bootstrap profiles; week-cluster multiplier coefficient refits; combined profile/coefficient uncertainty. Market simulations use prior out-of-fold market-relationship errors, condition smoothly on spread/total (fixed 7/10-point bandwidths, two-season decay), and transport paired errors to today's forecast. Scores are projected to nonnegative integers; margin/total parity is preserved. Weighted empirical samples retain dependence and non-Gaussian shape. Exponential tilting matches moneyline and conditional non-push spread/total probabilities. Calibration is a probability constraint, not independent validation of the market. Model-adjusted draws match the production win probability; this adds outcome shape, not a new win signal.

Feature simulation uses exponential multipliers shared by both sides of each historical game. Rebuild ratios of decayed counts with four fixed league pseudo-games, h8 main/h16 passing, and recompute products/hinges with frozen pregame reference normalization. Recenter bootstrap profile deviations on archived production inputs: upstream reconstructed boxes may differ from their historical archived versions. Availability and reference centers/scales stay fixed; their uncertainty is not identified by this resampling. This measures uncertainty conditional on those assumptions. Coefficients refit using exponential multipliers shared within season/week clusters, retaining original weekly age weights, standardization and fixed penalties. Training features remain their original pregame values. Separate components and combined draws are reported. These bootstrap ranges are sensitivity intervals, not proven frequentist confidence intervals for true game probabilities.

Default 256 profile draws, 64 coefficient refits, 8,192 outcome draws, seed 20261012. Bootstrap averages are candidate probabilities. Outcome Monte Carlo error and bootstrap probability ranges are separate. A second outcome seed checks numerical stability. A repeat with 512 profile draws, 128 coefficient refits and seed 20261013 checks bootstrap sensitivity. Market empirical probability ranges reweight earlier error records jointly by week-cluster exponential multipliers, holding fitted target centers fixed. Observed game variation remains separate from uncertainty in estimated probabilities.

Report all common-row win log loss/Brier, calibration bins, historical flat-unit returns and same-row market-favorite/null diagnostics; margin/total CRPS, 50/80/90% coverage, width, event probabilities, ties/pushes and tails. Paired week-cluster bootstrap intervals: 95% descriptive and simultaneous Bonferroni family intervals across challenger comparisons. Individual feature bootstrap SDs/correlations, effective residual sample sizes, source cutoffs, input hashes and seed are saved. Small neighborhoods shrink via broad positive kernel weights, not ad hoc distribution choices. No claim of improved accuracy without paired evidence; market quote capture times remain unknown.

Run `python research/monte_carlo.py --prepare-boxes`, then `python research/monte_carlo.py`. Results stay under `research/monte_carlo_results/`. Synthetic and chronology tests are in `tests/test_monte_carlo.py`.
